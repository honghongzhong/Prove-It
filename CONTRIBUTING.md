# Contributing

English · [简体中文](CONTRIBUTING.zh-CN.md)

Use focused changes and relevant tests. Follow [development instructions](docs/DEVELOPMENT.md).

Never commit research workspaces, conversations, credentials, databases, logs, environment files or generated packages. Stage only intended public files and run `python tools/release_audit.py`. Screenshots must use synthetic research.

Keep human review separate from Lean acceptance. Never substitute an auxiliary lemma for the complete target or claim verification without actually running Lean.

Maintain synchronized English and Chinese documentation. Default new installs to English, retain Chinese and preserve user preferences. See [Language policy](docs/LANGUAGE_POLICY.md).
