# 语言规范

[English](LANGUAGE_POLICY.md) · 简体中文

- 所有维护中的项目文档都提供同步的英文和中文版本。默认入口为英文 README.md 和无语言后缀的文件；中文使用 .zh-CN.md。两个版本互相链接。
- 发行说明先英文、后中文。文档中的链接优先指向读者所用语言的版本。
- 新工作区和安装向导在中文操作系统上也默认英文，并允许选择中文。升级保留已有用户的语言偏好。
- 切换界面语言不翻译研究内容或历史对话。
- 保留第三方许可证原文，提供双语说明而不替代法律原文。私密历史运行日志不属于维护中的公开文档或发布附件。
- 打包前检查文档配对和默认语言行为；使用空白配置验证默认值。
