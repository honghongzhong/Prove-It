# Language policy

English · [简体中文](LANGUAGE_POLICY.zh-CN.md)

- All maintained project documentation has synchronized English and Chinese versions. English is the default entry point: README.md and unsuffixed filenames. Chinese uses .zh-CN.md. Both versions link to each other.
- Release notes provide English first, followed by Chinese. Document links prefer the reader's language.
- Fresh application workspaces and installers default to English, including on Chinese operating systems. Chinese remains selectable. Upgrades preserve saved language preferences.
- Switching the interface language does not translate research or historical conversations.
- Keep third-party licenses unchanged; provide bilingual explanatory notices without replacing legal originals. Private historical execution logs are not maintained public documentation or release assets.
- Check document pairs and default-language behavior before packaging. Verify defaults using a fresh profile.
